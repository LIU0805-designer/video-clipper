# Video Clipper

A web app for clipping and processing recorded live-stream videos — originally built to help my mom edit her live-stream recordings. Browser UI, ffmpeg-powered processing on the backend.

## Tech stack

- Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4
- `@ffmpeg-installer/ffmpeg` for video processing
- `lucide-react` for icons

## Run locally

```bash
npm install
npm run setup   # first-time setup
npm run dev     # http://localhost:3000
# or
npm run serve   # http://localhost:3001
```
